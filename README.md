# ajayshekar001.github.io

Personal portfolio of Ajay Shekar. It's a static site with no build step.

- `data.js` holds all the content: profile, current work, projects and skills. Edit it to update the site.
- `index.html`, `styles.css` and `app.js` are the page layout, styles and rendering code.

Live at https://ajayshekar001.github.io
